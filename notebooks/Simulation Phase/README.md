# AI-Based Disaster Response Management System
## Simulation Phase Documentation

---

# Overview

The Simulation Phase demonstrates how the trained AI model can support disaster response planning after a disaster event has been detected.

Unlike the previous phases, this phase **does not train any machine learning models**. Instead, it uses the outputs generated from the prediction and allocation pipeline to simulate how emergency response agencies would react to a disaster.

The simulation follows the complete disaster response workflow, beginning with an affected disaster event and ending with a final mission report.

---

# Objectives

The Simulation Phase performs the following tasks:

- Simulate disaster response for individual disaster events
- Use the AI-predicted disaster severity
- Estimate affected population
- Select the nearest warehouse
- Allocate emergency resources
- Allocate temporary shelters
- Estimate transportation requirements
- Estimate travel time
- Produce a final disaster response report

# Simulation Inputs

Each disaster event contains the following information.

## Disaster Information

- Event ID
- Disaster Type
- Latitude
- Longitude
- Magnitude
- Depth
- Temperature
- Humidity
- Rainfall
- Wind Speed

## AI Prediction

The trained Random Forest model predicts

- Severity
  - Low
  - Medium
  - High

The predicted severity is then used throughout the remaining simulation.

---

# Population Estimation

The system estimates

- Total affected population
- Children
- Adults
- Elderly
- Vulnerability score

These values determine the required emergency resources.

---

# Warehouse Selection

For every disaster event,

the nearest warehouse is selected using the Haversine Distance formula.

Warehouse information includes

- Warehouse Name
- State
- Latitude
- Longitude
- Distance from disaster

---

# Inventory Allocation

The warehouse inventory contains

- Food Packets
- Water Bottles
- Medical Kits
- Blankets
- Temporary Tents

For every resource,

the simulation calculates

Required

Allocated

Shortage

Remaining Inventory

---

# Shelter Allocation

The nearest shelters are searched.

People are allocated until shelter capacity becomes full.

The simulation reports

- People requiring shelter
- People sheltered
- Remaining people
- Number of shelters used
- Shelter status

Possible status

- Fully Allocated
- Partially Allocated
- No Shelter Available

---

# Transportation Planning

Transportation resources are estimated using allocation results.

Resources include

- Supply Trucks
- Ambulances
- Rescue Teams
- Rescue Buses
- Helicopters
- Boats (Flood only)

The notebook estimates

- Required vehicles
- Travel time
- Mission requirements

---

# Mission Status

Mission status is generated using both

Inventory Allocation Status

and

Shelter Allocation Status.

Possible outputs

Mission Ready

Limited Response

Mission Failed

---

# Final Disaster Report

For every disaster event,

the simulation produces a complete operational report containing

- Disaster Details
- AI Prediction
- Warehouse Assignment
- Resource Allocation
- Shelter Allocation
- Transportation Requirements
- Remaining Warehouse Inventory
- Mission Status

This report represents the complete response generated by the system.

---

# Simulation Demonstration

Two disaster events are simulated.

## Scenario 1

Earthquake

Demonstrates a disaster where

- inventory is largely sufficient
- shelters are available
- mission can be completed successfully

## Scenario 2

Flood

Demonstrates a large-scale disaster where

- resource shortages occur
- shelter capacity becomes insufficient
- transportation requirements increase
- mission becomes partially successful

This allows comparison between two different disaster situations.
